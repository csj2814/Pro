## 2. 논의 내용

### 2-1. 프로토타입 실증 결과
자체 프로토타입 실증에서 **다중 인원 낙상 인식 정확도 97.9%**를 확인함

### 2-2. 제품명 확정
가칭 후보 검토 끝에 **SolCare**로 확정함

### 2-3. 수면 검사 결과지 양식
- 첨부 참고 이미지를 근거로 **인바디(InBody) 결과지 구조 + 하늘색 톤 리포트**를 결합한 A4 한 장 양식으로 확정.
- 구성: 대상자 정보 표(가명 ID 기준) → 수면 구조(하이포그램) → 단계 비율 → 생체 신호 → 무호흡 스크리닝 → 야간 활동·안전 → 수면 점수·유형 매트릭스 → LLM 아침 요약 → 프라이버시 고지.
- 결과지 하단에 "생활 관찰용이며 의학적 진단을 대체하지 않음" 면책 문구 필수로 합의. 무호흡은 "진단"이 아닌 "스크리닝"으로 표기.

### 2-4. 데이터 규격 및 스프린트 계획
- 결과지 수치와 일치하는 **합성 샘플 데이터셋**으로 스키마를 확정: 1Hz 시계열 CSV(심박·호흡·진폭·움직임·침대 체류·수면 단계), 이벤트 라벨 CSV, 세션 메타데이터 JSON.
- 파일 명명 규칙: `{날짜}_{세션번호}_{침대ID}_{종류}.csv`
- 저장소 원칙 재확인: **개인 식별 가능한 건강 데이터(원본 시계열·실명 매핑)는 저장소에 올리지 않음.** 가명 ID만 사용, 원본은 별도 보관.

## 3. 의사결정

1. 제품명 **SolCare** 확정.
2. 수면 검사 결과지 양식(A4 1장) 확정 — 면책 문구 포함.
3. 샘플 데이터 스키마(시계열/이벤트/메타 3종) 확정.

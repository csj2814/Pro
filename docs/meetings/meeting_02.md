| 항목 | 내용 |
|---|---|
| 일시 | 2026-10-14(화) 오후 |
| 장소 | 학교 팀룸 |

## 1. 안건

1. 시스템 계층 구조 설계
2. 다중 인원 분리 추적 방안
3. 실사용 흐름(하루 타임라인) 정의
4. 팀원별 역할 분담 확정

## 2. 논의 내용

### 2-1. 시스템 구조
**센싱 – 엣지 – 데이터 – AI – 서비스**의 다섯 계층 구조로 설계하기로 함.

| 계층 | 역할 |
|---|---|
| 센싱 | mmWave 레이더 + 보조 센서로 생체 신호 획득 |
| 엣지 | 현장 1차 판단(이벤트 감지) |
| 데이터 | 시계열 데이터 저장·관리 |
| AI | 이상 예측 |
| 서비스 | 대시보드, 보호자 앱, 알림 |

### 2-2. 다중 인원 분리 추적
센서 한 대로 한 방의 최대 세 명을 동시에 모니터링하기 위한 매핑 알고리즘 채택. 회의에서는 편의상 "1센서 1인 매핑"으로 불렀으나, 표현이 "1센서 다인" 개념과 혼동된다는 지적이 있어 문서 표기는 **1센서 다인 분리 매핑**으로 통일하기로 함.

### 2-3. 실사용 흐름
하루 타임라인을 다음과 같이 정의함.
- 21시 취침 감지
- 02시 무호흡 스크리닝
- 03시 30분 낙상 자동 반응 + 복도 조명 점등
- 06시 아침 리포트 정리

### 2-4. 역할 분담

| 팀원 | 담당 |
|---|---|
| 최우성 | 사업 모델 설계, 발표 총괄, 사용자 시나리오 정의 |
| 박찬혁 | mmWave 모듈 + 보조 센서 통합, 데이터 수집 |
| 임동혁 | 데이터베이스, 대시보드, 예측 모델, 보호자 앱 |
| 문정현 | 학습 데이터 수집 및 라벨링 표준화 |

## 3. 의사결정

1. 5계층 구조 확정.
2. 다중 인원 분리는 침대 단위 매핑으로 구현하기로 함.
3. 역할 분담 확정 — 문서·회의록 관리는 최우성이 겸함.

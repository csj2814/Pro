## 1. 1주차 회의에서 확정된 내용 (시나리오의 전제)

| 항목 | 확정 내용 |
|---|---|
| 문제 정의 | 야간 돌봄의 공백 = 사생활 침해와 인간 존엄 사이의 충돌 |
| 기존 방식의 한계 | CCTV — 촬영 자체가 사생활 침해, 야간 저조도 오탐 / 웨어러블 — 착용 거부·분실·충전·세탁·누락 등 운영 부담 |
| 해법 | 60GHz mmWave 비접촉 레이더 — 영상 저장 없이 시계열 신호로만 호흡·심박·무호흡·낙상 감지 |
| 핵심 가치 | ① 비접촉 ② 프라이버시 보호(영상·음성·이름 없음) ③ 다중 모니터링(1센서 3침대) |

시나리오의 모든 등장인물은 이 전제 위에서 SolCare를 사용합니다. 어르신은 **아무것도 착용하지 않고, 촬영되지 않으며**, 보호자는 **이름이 아닌 가명 ID(P001 등)로만** 상태를 확인합니다.

## 2. 대상 사용자

| 사용자 | 상황 | 니즈 |
|---|---|---|
| 어르신 (75~85세) | 재가 또는 요양원에서 생활, 밤낮 뒤바뀐 수면·야간 화장실 이동 잦음 | 손에 거는 장치 없이 잠자리 방해받지 않기 |
| 보호자 (자녀 세대) | 떨어져 사는 부모 야간 안전 불안, 순찰·전화 확인 반복 | 밤사이 이상을 바로 알고, 아침에 한눈에 확인 |
| 요양원 야간 인력 | 1인이 여러 호실 담당, 순찰·기록 업무 과중 | 이상 호실만 골라 알림받고 기록 부담 줄이기 |


## 3. 하루 시나리오 (타임라인)

### 시나리오 A — 재가 돌봄: 떨어져 사는 딸과 어머니

밤 9시 47분, 어머니가 침대에 누우자 **센서가 취침을 감지**하고 보호자 앱에 "취침 감지(21:47)"가 조용히 기록됩니다. 새벽 2시, 무호흡 스크리닝이 짧은 호흡 정지를 관찰 기록으로 남깁니다 — 이때는 긴급 상황이 아니므로 앱을 깨우지 않습니다. 3시 30분, 화장실 가던 어머니가 넘어질 듯하자 **낙상 감지 → 즉시 보호자 알림(30초 이내) + 복도 조명 자동 점등**으로 어머니를 보호합니다. 아침 6시, 보호자는 앱을 열고 **LLM이 쉬운 문장으로 정리한 아침 리포트** 하나로 어머니의 밤을 확인합니다. 영상은 어디에도 없습니다.

### 시나리오 B — 요양원: 1인 야간 인력의 3인실 케어

야간 인력 1명이 센서 1대로 3침대(A·B·C)를 동시 모니터링합니다. 침대 A 대상자가 몇 차례 뒤척이다 **침대를 이탈**하자 복도 조명이 점등되고, 이탈·복귀가 신호 기반으로 기록됩니다. 낙상이 감지되면 가장 가까운 담당자에게 즉시 알림이 갑니다. 아침에는 호실별 리포트가 생성되어 **야간 인수인계 기록으로 그대로 활용**됩니다. 어느 대상자의 영상도 촬영되지 않으므로, 사생활 침해 민원 가능성이 구조적으로 낮습니다.

## 4. 프라이버시 원칙이 시나리오에 드러나는 방식

- 어르신의 얼굴·목소리·이름은 어디에도 저장·전송되지 않습니다 — 앱 화면에는 **가명 ID(P001)·침대 A/B/C**만 표시됩니다.
- 보호자가 보는 것은 시계열 신호에서 뽑은 수치와 LLM이 서술한 문장뿐입니다.
- 긴급 알림(낙상·무호흡)은 LLM 생성을 기다리지 않고 즉시 발송되고, LLM 리포트는 아침 전달용으로만 쓰입니다(3주차 회의 확정 사항 반영).

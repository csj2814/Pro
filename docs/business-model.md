# SolCare 사업 모델 설계

| 상태 | 최신 |

## 1. 문제 → 기회

초고령 사회의 야간 돌봄 공백은 사생활 침해와 인간 존엄 사이의 충돌입니다. CCTV는 촬영 자체가 사생활 침해이고 웨어러블은 운영 부담이 커서, 두 시장 모두 돌봄 품질과 존엄을 동시에 만족시키지 못합니다. SolCare는 **카메라도 웨어러블도 없는 비접촉 야간 돌봄**이라는 미충족 수요를 정면으로 겨냥합니다.

## 2. 고객 세그먼트

| 세그먼트 | 니즈 | 진입 우선순위 |
|---|---|---|
| 요양원·요양병원 | 1인 야간 인력의 다중 호실 케어, 민원 저감 | 1순위 (B2B) |
| 재가 돌봄 가정 | 떨어져 사는 가족의 야간 안전 확인 | 2순위 (B2C) |
| 글로벌 IoT 헬스케어 | 영상 없는 돌봄 솔루션 수요 | 3순위 (해외) |


## 3. 수익 모델 — 이중 수익화

1. **하드웨어 판매** — 60GHz mmWave 센서 1대(호실 단위, 침대 3개 동시 커버) 판매
2. **SaaS 구독** — 웹 대시보드 + 보호자 앱 + LLM 아침 리포트·누적 리포트·AI 분석 제공

구독의 핵심 가치는 **누적 리포트와 AI 분석**입니다. 리포트가 쌓일수록 수면의 질·심박 변화 추세를 일찍 발견해 해지 가능성이 낮아집니다. 요양원용으로는 LLM 리포트를 **야간 인수인계 일지 자동 작성**에 활용해 기록 업무 부담을 줄입니다.


## 4. 차별화 포인트

| 구분 | CCTV | 웨어러블 | **SolCare** |
|---|---|---|---|
| 접촉 | 비접촉 | 착용 필수 | **비접촉·비착용** |
| 사생활 | 촬영 자체가 침해 | 양호 | **영상·음성·이름 없음(시계열 신호만)** |
| 운영 부담 | 야간 오탐 | 충전·세탁·분실·누락 | **설치 후 무관리** |
| 커버리지 | 호실 단위 | 1인 1개 | **1센서 3침대 동시** |
| 전달 | 영상 확인 | 앱 확인 | **긴급 즉시 알림 + LLM 아침 리포트** |

## 5. 기대효과 (3축)

1. 보호자의 야간 심리 부담 경감 — 순찰 없이 이상 상황 30초 이내 인지 [근거 수치 확인 필요]
2. 요양원의 다중 호실 동시 케어 효율화 — 1인 인력으로도 돌봄 품질 유지
3. 영상 없는 돌봄의 기준 제시 — 사생활 침해 민원 가능성 구조적 저감

## 6. 활용 시나리오 4단계 로드맵

1. **요양원·요양병원 야간 호실 운영** — B2B 파일럿으로 다중 호실 실증
2. **재가 돌봄 확장** — 가정용 소형 패키지, 보호자 앱 중심
3. **글로벌 IoT 헬스케어 진입** — 하드웨어 + SaaS 이중 수익화
4. **의료기기 인증 후 디지털 헬스케어 표준 확장** — 생활 관찰 스크리닝을 넘어 인증 범위 확대 [인증 절차 일정 확인 필요]

## 7. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| LLM 사용과 프라이버시 원칙의 충돌 우려 | 집계 수치·가명 ID만 전달, 원시 신호 미전송 (3주차 회의 확정) |
| 의료 행위 오해 | 진단 아닌 스크리닝 표기, 면책 문구 상시 노출 |
| 오탐·미탐 | 긴급 알림 이원화 + 라벨링 표준 기반 모델 개선 |

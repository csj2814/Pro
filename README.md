# SolCare 

> 카메라도 웨어러블도 없이, 센서 한 대로 한 방의 세 침대를 동시에 지키는 야간 돌봄 시스템

60GHz mmWave 비접촉 레이더 센서 한 대로 한 방의 최대 세 명의 생체 신호를 동시에 모니터링합니다.
영상·음성·이름을 저장하지 않고 시계열 신호만으로 호흡·심박·수면·무호흡·낙상을 감지하고,
LLM 아침 리포트로 보호자에게 전달합니다.

## 문제 정의와 기획의도

초고령 사회로 진입하면서 야간 돌봄의 공백은 단순한 노동력 부족이 아니라
사생활 침해와 인간 존엄 사이의 충돌로 재정의되어야 합니다.

기존 야간 모니터링은 두 가지 방식입니다.

- **CCTV** — 비접촉 방식이지만 촬영 자체가 곧 사생활 침해이며, 야간 저조도에서 오탐이 잦습니다.
- **웨어러블 밴드** — 생체 신호를 직접 측정할 수 있지만 착용 거부, 분실, 충전, 세탁, 누락 등 운영 부담이 매우 큽니다.

두 방식 모두 돌봄의 수준과 인간 존엄을 동시에 만족시키지 못합니다.
저희는 이 문제를 **카메라도 웨어러블도 없이, 손대지 않고도 더 정확히 지킬 수 있는
비접촉 돌봄의 기준**으로 다시 정의하려 합니다.

60GHz mmWave 전자기파는 체표면의 미세 떨림까지 읽어낼 수 있어,
호흡·심박·무호흡·낙상 등을 영상 저장 없이 시계열 신호로만 전달할 수 있습니다.
이 신호는 개인 식별 정보 없이 보호자 앱과 웹 대시보드로 전달되며,
어르신의 사생활은 어디에도 가지 않고 보호됩니다.

## 핵심 가치

1. **비접촉** — 카메라도 웨어러블도 없는 야간 돌봄
2. **프라이버시 보호** — 영상·음성·이름 없이 시계열 신호만 사용
3. **다중 모니터링** — 센서 한 대로 한 방의 세 침대를 동시에 케어
4. **AI 아침 리포트** — 밤사이 수면·호흡·심박·이벤트를 LLM이 요약해 매일 아침 보호자에게 전달

## 시스템 구성

센싱 – 엣지 – 데이터 – AI – 서비스의 다섯 계층 구조로 구성됩니다.

| 계층 | 역할 |
|---|---|
| 센싱 | mmWave 레이더 + 보조 센서로 생체 신호 획득 |
| 엣지 | 현장 1차 판단 (이벤트 감지) |
| 데이터 | 시계열 데이터 저장·관리 |
| AI | 이상 예측, LLM 아침 리포트 생성 |
| 서비스 | 대시보드, 보호자 앱, 알림 |

1센서 다인 분리 매핑 알고리즘으로 다중 인원을 분리 추적합니다. 

## 실사용 흐름

```
21:00  취침 감지
02:00  무호흡 스크리닝
03:30  낙상 자동 반응 + 복도 조명 점등
06:00  LLM 아침 리포트 생성 + 보호자 알림
```

다중 인원 낙상 인식 정확도 **97.9%** — 자체 프로토타입 실증 결과

# SolCare 데이터 수집 가이드

| 항목 | 내용 |
|---|---|
| 작성·관리 | 문정현 (학습 데이터 수집 담당) · 환경 기록 협조: 박찬혁 |

---

## 1. 목적과 수집 대상 이벤트

60GHz mmWave 비접촉 레이더 + 보조 센서로 다음 신호·이벤트를 수집합니다.

| 대상 | 설명 |
|---|---|
| 호흡 · 심박 | 체표면 미세 떨림 기반 추정치 (1Hz 시계열) |
| 수면 단계 | wake / light / deep / rem |
| 무호흡 의심 | **호흡 정지 4초 이상**(팀 기준) — 의학적 진단 아님 |
| 낙상·넘어짐 | fall / near_fall |
| 침대 이탈·뒤척임 | bed_exit / toss |

## 2. 수집 환경 기록 (세션마다 필수)

세션 시작 전 메타데이터에 기록합니다.

- 일시(KST), 장소, 조도, 침대 간격, 센서 설치 높이·각도: [확인 필요]
- 센서 펌웨어 버전, 보조 센서 구성: [확인 필요]
- 참가자 **가명 ID**(예: P001)와 침대 ID(A/B/C) — 실명은 기록하지 않습니다.

## 3. 세션 절차

1) 환경 기록 → 2) 수집 시작 → 3) 이벤트 발생(필요시 연출) → 4) 종료·백업 → 5) 비식별 체크리스트 통과

## 4. 파일 명명 규칙

```
{날짜}_{세션번호}_{침대ID}_{종류}.csv|json
예시: 20261103_s01_bedA_vitals_1hz.csv
      20261103_s01_bedA_events_labels.csv
      20261103_s01_bedA_session_meta.json
```

날짜는 **세션 시작일** 기준입니다.

## 5. 데이터 형식 

**시계열 CSV (1Hz)** — `timestamp_kst, bed_id, pseudo_id, heart_rate_bpm, respiration_rate_bpm, breath_amplitude_pct, movement_index, in_bed, sleep_stage`

**이벤트 라벨 CSV** — `event_id, event_type, start_time_kst, end_time_kst, duration_s, bed_id, pseudo_id, label_source, note`

**세션 메타 JSON** — session_id, 장비, 창, 주파수 대역, 타임존, 데이터 정책 고지


## 6. 비식별 처리 원칙

- 실명·연락처·영상·음성은 **원천적으로 수집·저장하지 않습니다.**
- 가명 매핑표(P001 ↔ 실명)는 **저장소에 올리지 않고 담당자 개인 PC에 로컬 보관**합니다.
- 원본 데이터는 개인 PC 로컬에 보관하고, 저장소에는 비식별 샘플만 올립니다.

## 7. 저장소 반영 절차

1) 비식별 체크리스트 통과 → 2) `data/samples/` 형식에 맞게 축소본만 추가 → 3) 원본 보관 장소 기록 → 4) 커밋

커밋 예시: `data: 비식별 샘플 1종 추가` / `docs: 데이터 수집 방법 문서 최종본`

## 8. 수집한 데이터의 정리 내용

세션이 끝날 때마다 [data-summary.md](data-summary.md)에 다음을 누적 기록합니다.

- 세션 목록(날짜·침대·참가자 가명·길이)
- 이벤트 통계(무호흡 의심 건수, 뒤척임, 이탈 횟수 등)
- 품질 점검(결측 구간, 센서 이상 여부)

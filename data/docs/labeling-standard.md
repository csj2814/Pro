# SolCare 라벨링 표준

| 항목 | 내용 |
|---|---|
| 작성·관리 | 문정현 (라벨링 표준화 담당) · 검수: 박찬혁 |
| 상태 | 최신 |

---

## 1. 라벨 정의표

### 수면 단계 (시계열 CSV의 `sleep_stage`)

| 라벨 | 정의 | 시작/종료 기준 |
|---|---|---|
| `wake` | 깨어 있음(침대 안 각성) | 비공개 |
| `light` | 얕은 잠 | 비공개 |
| `deep` | 깊은 잠 | 비공개 |
| `rem` | 렘수면 | 비공개 |

### 이벤트 라벨 (이벤트 라벨 CSV의 `event_type`)

| 라벨 | 정의 | 판정 기준 |
|---|---|---|
| `apnea_suspected` | 무호흡 의심 | **호흡 정지 4초 이상**(팀 기준) + 진폭 임계값  |
| `toss` | 뒤척임 | movement_index 급상승 구간  |
| `bed_exit` | 침대 이탈 | in_bed = 0 구간 |
| `fall` | 낙상 | 모델 판정 + 관찰 기록 일치 |
| `near_fall` | 넘어짐 시도 | 400번 |
| `sleep_onset` / `final_wake` | 입면 / 기상 | 첫 수면 단계 진입 / 마지막 깨어있음 |

## 2. 시간 표기

- KST(Asia/Seoul), 초 단위 타임스탬프.
- 이벤트 라벨에는 절대시간과 **세션 시작 시각 기준 상대시간**을 함께 기록합니다.

## 3. 경계 처리

- 이벤트 시작·종료 모호 구간은 전후 여유를 두고 표기합니다.
- 무호흡은 의학적 진단이 아니므로 라벨명을 항상 `apnea_suspected`(의심)로 유지합니다.

## 4. 라벨링 절차

1. **1차 라벨링** — 문정현
2. **2차 검수** — 박찬혁 (동일 구간 독립 검토)
3. **불일치 처리** — 팀 논의로 확정, 결과를 라벨 파일에 반영

## 5. 품질 기준

- 검수 일치율 목표:94%
- 불일치 구간 목록과 최종 판정 사유를 검수 기록으로 남깁니다.
## 6. 버저닝

- 기준(정의·임계값·절차)이 바뀌면 버전을 올리고 변경 사유를 본 문서에 기록합니다.

## 7. 라벨 파일 예시

라벨 파일 원본은 개인 PC 로컬 보관 대상이며, 저장소에는 비식별 샘플만 올립니다.

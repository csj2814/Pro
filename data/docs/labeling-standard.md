# 합성 mmWave 데이터 라벨링 표준 v1.0

## 목적과 제한

이 데이터는 SolCare의 분류 파이프라인 개발, 화면 시연, 입출력 형식 검증을 위한 **합성 데이터**다. 실제 거주자의 생체 데이터가 아니며 의료 판단, 임상 성능 평가, 정확도 홍보에는 사용할 수 없다.

각 행은 센서가 한 사람에게서 관측한 30초 구간 하나를 나타낸다. 한 구간에는 가장 우선순위가 높은 이벤트 하나만 라벨링한다.

## 라벨 정의

| ID | 라벨 | 의미 | 심각도 |
|---:|---|---|---|
| 0 | `normal` | 안정적인 호흡·심박과 낮은 움직임 | `none` |
| 1 | `apnea` | 호흡 신호가 매우 낮거나 일시적으로 끊긴 구간 | `high` |
| 2 | `tachycardia` | 심박이 비정상적으로 높은 패턴 | `medium` |
| 3 | `bradycardia` | 심박이 비정상적으로 낮은 패턴 | `medium` |
| 4 | `fall` | 큰 움직임과 급격한 거리·높이 변화가 함께 발생 | `critical` |
| 5 | `bed_exit` | 침대에서 벗어나는 지속적인 이동 패턴 | `low` |

실제 수집 데이터에 적용할 임계값은 의료진 검토와 센서 검증을 거쳐 별도로 확정해야 한다. 현재 수치는 합성 샘플 생성용 분포일 뿐 임상 기준이 아니다.

## 컬럼 정의

| 컬럼 | 형식 | 설명 |
|---|---|---|
| `segment_id` | string | 분할·대상·구간을 조합한 고유 ID |
| `timestamp` | ISO 8601 | 30초 구간 시작 시각 |
| `subject_id` | string | 합성 익명 대상 ID |
| `room_id` | string | 합성 방 ID |
| `bed_id` | integer | 방 안 침대 번호(1~3) |
| `tracked_people` | integer | 동시에 추적된 인원 수 |
| `respiration_bpm` | float | 분당 호흡수 추정값 |
| `heart_rate_bpm` | float | 분당 심박수 추정값 |
| `motion_energy` | float | 정규화된 움직임 에너지(0~1) |
| `range_change_m` | float | 구간 내 레이더 거리 변화량(m) |
| `body_height_change_m` | float | 추정 신체 높이 변화량(m) |
| `signal_quality` | float | 정규화된 신호 품질(0~1) |
| `label_id` | integer | 모델 학습용 숫자 라벨 |
| `label` | string | 사람이 읽는 라벨명 |
| `severity` | string | 서비스 알림 우선순위 |

## 분할 원칙

- `train.csv`: S001~S054, 12,498행
- `validation.csv`: S055~S072, 4,182행
- `test.csv`: S073~S090, 4,181행
- 이상치 제거 후 전체 데이터는 합성 대상 90명의 30초 구간 20,861행으로 구성한다.
- 동일 대상은 둘 이상의 분할에 들어가지 않는다. 대상 특성이 학습·평가 양쪽에 섞이는 데이터 누수를 방지하기 위한 기준이다.
- 생성 시드와 알고리즘은 `data/generate_synthetic_data.py`에 고정되어 있어 같은 파일을 재현할 수 있다.

## 이상치 제거 기준

1. `respiration_bpm`, `heart_rate_bpm`, `motion_energy`, `range_change_m`, `body_height_change_m`, `signal_quality`를 검사한다.
2. 학습 데이터에서 라벨과 특징별로 1사분위수(Q1), 3사분위수(Q3), 사분위 범위(IQR)를 계산한다.
3. `Q1 - 1.5 × IQR` 미만이거나 `Q3 + 1.5 × IQR`을 초과하는 값이 하나라도 있는 행을 제거한다.
4. 검증·테스트 데이터에는 학습 데이터에서 계산한 경계만 적용한다. 평가 데이터의 분포가 전처리 기준에 섞이는 것을 방지한다.
5. 이 기준은 합성 데이터의 통계적 정리를 위한 것이며 임상 정상 범위나 의료 판단 기준이 아니다.

제거 결과는 학습 462행, 검증 138행, 테스트 139행이다. 이상치 행을 삭제하므로 각 대상의 구간 번호에는 빈 번호가 있을 수 있다.

## 실제 데이터 라벨링 시 권장 절차

1. 센서 구간과 현장 관찰 기록의 시각을 동기화한다.
2. 두 명이 독립적으로 라벨링하고 불일치는 제3 검토자가 확정한다.
3. 신호 품질이 낮아 판정할 수 없는 구간은 향후 `unknown` 라벨로 분리하고 학습에서 제외한다.
4. 개인 식별 정보와 원본 실명 매핑은 저장소에 커밋하지 않는다.
5. 분할은 행 단위가 아니라 사람 또는 수집 세션 단위로 수행한다.
